# IGA Service Objectives

## Service name

`iga-service`

## Simulated platform type

Identity Governance and Administration platform.

Examples of real-world platform categories:

```text
SailPoint IdentityIQ
SailPoint Identity Security Cloud
Saviynt
Omada
One Identity Manager
```

## Primary learning objective

Learn how IGA normalizes identity, account, entitlement, assignment, application, and correlation data to govern access.

## What this service teaches

```text
Application onboarding catalog
Identity normalization
Account aggregation
Entitlement aggregation
Account-entitlement assignment mapping
Correlation logic
Orphan account detection
Access risk visibility
Future access request, approval, certification, and provisioning concepts
```

## Milestone 1 scope

Milestone 1 creates:

```text
application catalog
normalized identity data
normalized account data
normalized entitlement data
normalized assignment data
correlation result data
GraphQL schema design
validation tests
```

## Out of scope for Milestone 1

```text
Real SailPoint connector logic
Real provisioning
Real approvals
Real certification campaigns
Real policy engine
Real UI
Production integration
```

## Future scope

Later versions may add:

```text
GraphQL resolver implementation
aggregation scripts from HRMS, IdP, and JDBC target
request/approval workflow
certification review model
provisioning simulation
SOD policy simulation
IGA governance UI
AI-assisted access review recommendations
```
